# Iris-Classifier (Decision Tree)
Machine learning project that classifies Iris flower species using two supervised learning algorithms: Decision Tree Classifier and K-Nearest Neighbors (KNN) Classifier.

## Overview
End-to-end ML example from Digital Marketing Mastery Module → builds a decision-tree classifier on the classic Iris dataset using scikit-learn.
